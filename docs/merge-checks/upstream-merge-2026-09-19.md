# Upstream merge ledger — 2026-09-19

Range: `c375b20a4..origin/master` (`d9550da6b`), 35 commits, linear history.
Method: [`docs/Architecture/upstream-merge-workflow.md`](../Architecture/upstream-merge-workflow.md), run in
batches on branch `merge-upstream-2026-09-19` (separate worktree). Each upstream commit is merged
by SHA so ancestry is real; **every GPU-renderer commit is its own merge commit**, recorded with
`-s ours` (no GPU code imported) plus hand-ported *only* what is a genuine core bug fix.

Policy (GPU commits are unreviewed upstream, see `opengl-renderer-review.md`): a hunk is taken only
if it fixes behaviour that exists on the **software** path today. Anything that only makes sense
once a GL backend exists (`RendererSetScreenTint`, `RendererBeginFrame`, `UIRenderer_Submit*`,
`RendererPhysicalWidth`, lens/atlas/IR plumbing, …) is not taken.
